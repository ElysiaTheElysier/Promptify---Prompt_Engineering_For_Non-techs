Dưới đây là mã nguồn hoàn chỉnh của UI-05.html — Consolidated Master Workspace (Không gian làm việc Hiện đại cho Người học).

Màn hình này tích hợp toàn bộ tinh hoa:

Bố cục 3 cột công thái học (Ergonomics): Cột trái có thể thu gọn (Collapse/Expand) bằng một click hoặc phím tắt để mở rộng không gian viết và đối chiếu.
Hiển thị song song (Parallel Observability): Giữ nguyên cả Prompt Composer và Live Output cùng lúc (không bị giấu sau tab như bản cũ).
Giàn giáo Sư phạm (Pedagogical Scaffolding): Tích hợp lại toàn bộ hệ thống Chip Popovers (giải thích Tác động đầu ra và Ví dụ mẫu) của bản cũ, được định vị chuẩn mực kèm mũi tên (caret).
Bàn thử nghiệm đa dữ liệu (Multi-Input Test Bench): Chuyển đổi nhanh giữa các Test Case (dữ liệu bình thường vs. dữ liệu bẫy PII).
Tích hợp sẵn 2 Side-Over Drawers (UI-07 & UI-08):
Bấm mở ngay SOP Context Inspector (UI-08) để tra cứu và copy mã trích dẫn (Ctrl + \).
Bấm mở ngay AI Judge Diagnostic Scorecard (UI-07) để xem chi tiết 5 tiêu chí Rubric.
Hệ thống phím tắt & Design System: Chuẩn Material Design 3 (M3) + JetBrains Mono + Alpine.js reactive mượt mà.

        const textarea = document.getElementById('promptTextarea');
        if (!textarea) {
            this.promptText += '\n\n' + textToInsert;
        } else {
            const start = textarea.selectionStart;
            const end = textarea.selectionEnd;
            const before = this.promptText.substring(0, start);
            const after = this.promptText.substring(end);
            this.promptText = before + (before.endsWith('\n') || before === '' ? '' : '\n\n') + textToInsert + (after.startsWith('\n') ? '' : '\n\n') + after;
