1. CONFIRMED PHASE-1 DIRECTION
==================================================

Treat these as confirmed unless stronger evidence contradicts them:

- Phase 1 is an INTERNAL Promptify version for Intrepid.
- Not a generic multi-tenant SaaS yet.
- Target users:
  1. Intrepid Learner
  2. Vo Tu Duc / Trainer
  3. Department Head / Admin
- Intrepid has multiple Business Functions across multiple countries.
- Corporate Intrepid SSO.
- Users are pre-onboarded from roster data.
- After login, user confirms:
  - email
  - full name
  - business function / department
  - country
- User is routed to their department-specific learning zone.
- Training content should use:
  - Intrepid SOPs
  - department-specific sample data
  - trainer-created exercises
- Department Heads may:
  - confirm/update SOP information
  - provide sample operational data
  - view department learning results
  - view department prompt library
- Vo Tu Duc is the primary trainer/admin for Phase 1.
- All Intrepid users are treated as paid users.
- No payment/subscription flow is required in Phase 1.
- End users do NOT provide their own AI API key.
- AI credentials are controlled backend-side by Intrepid.
- English + Vietnamese should be supported through i18n architecture.
- Analytics/reporting is important.
- Success with Intrepid should create a reusable pattern for future enterprise deployments.
- Generic multi-tenant / Agribank-style cloning is Phase 2, not the first implementation target.
